## Context

The gate every PR passes. Its most important property is that integration tests actually run —
a suite that silently skips in CI is worse than no suite, because it reads as a pass.

Read [testing.md](../../docs/context/testing.md) § *CI*.

## Acceptance criteria

- [ ] Runs on PRs and on pushes to `main`
- [ ] Lint · typecheck · test with coverage · build. All four must pass
- [ ] A **Postgres 17 service container**, with `DATABASE_URL_TEST` set, so integration tests run
      for real
- [ ] **CI fails if `DATABASE_URL_TEST` is unset** — the skip that's correct locally is a false
      pass here (T003 already encodes this; verify it fires)
- [ ] Coverage thresholds enforced: `src/lib/money/**` 95%, `src/server/services/**` 80%
- [ ] Node version pinned and matching the Dockerfile
- [ ] Dependency caching, and a total runtime that doesn't discourage small PRs
- [ ] `npm run test:ci` locally reproduces CI exactly

## Out of scope

Building or publishing an image (T072).
